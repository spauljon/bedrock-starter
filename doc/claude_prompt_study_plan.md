## Quick Reference: Essential Techniques

**The Big 5 that solve most problems:**
1. **Be specific** - Replace "write about X" with "write a 3-paragraph analysis of X covering Y and Z"
2. **Use examples** - Show Claude exactly what you want with 1-2 concrete examples
3. **Think step by step** - Add "Let's think through this step by step" for complex tasks
4. **Assign roles** - "You are an expert..." sets helpful context
5. **Format clearly** - Use XML tags, bullet points, or clear structure
